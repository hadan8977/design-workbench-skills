# Apple-inspired visual language

Apply these principles when this aesthetic was requested. Yu Apple's upstream defaults describe presentation design, not universal Apple platform tokens.

## Stable anchors, varied composition

Start with near-black text, light neutral surfaces, generous space, a clear focal point, and selective emphasis. Light, broad shadows can support depth. Approved brand tokens override the examples below.

Yu Apple's deck starting points, on a 1920×1080 canvas:

| Element | Starting point |
| --- | --- |
| Main text / dark surface | `#1D1D1F` / `#050506` |
| Light surfaces | `#FFFFFF`, `#F5F5F7` |
| Secondary text | `#86868B`; deepen to `#626268` where readability requires it |
| Accent | `#0071E3`; a small cyan-to-blue-violet gradient can emphasize a key word |
| Chinese fonts | PingFang SC, Noto Sans CJK SC, Noto Sans SC, Microsoft YaHei, sans-serif |
| Latin fonts | Helvetica Neue, Arial, sans-serif; SF Pro only if available and licensed |
| Horizontal / vertical safe space | 96–128 px / 64–96 px |
| Statement / normal title | 84–132 px / 56–80 px |
| Subheading / body / source note | 34–48 px / 24–32 px / 15–20 px |
| Large / small radius | 48–72 px / 20–36 px |

Check contrast on the actual background; muted gray is not automatically suitable for body copy or interactive labels. No fonts are distributed with this skill.

## Translate to websites and interfaces

Translate relationships, not slide measurements: strong hierarchy, stable margins, deliberate imagery, restrained accents, and clear primary actions. Use the project's responsive type, spacing, content widths, and components. Operational screens can need dense controls, tables, and persistent navigation; preserve the tasks rather than turning them into marketing slides.

Apple-inspired styling does not require glass, blue accents, or a new component library. Materials need a layering purpose, readable content, and appropriate fallbacks. Familiar system fonts and white or near-black surfaces can be intentional choices; judge them against the brief instead of an unrelated ban list.

## Composition and imagery

- Choose one strong focal point where appropriate. Crop for the subject and action rather than a fixed image percentage.
- Stable margins and alignments support asymmetry; text and imagery need not occupy equal areas.
- Group parallel content with shared geometry and baselines. Use connectors for process and causality instead of unrelated cards.
- Mirror device shells or views as needed while keeping text and UI readable and inside the screen opening.
- Give each main visual a purpose: evidence, context, metaphor, process, or pacing. Prefer real assets for factual claims; label generated illustrations and proposals accurately.
- Track source images separately from final crops. A larger export canvas does not create photographic detail.

In decks, vary page role, density, image scale, background, and reading direction as the narrative needs. Comparable examples can share a composition. Do not impose a dark-page quota or vary layouts solely for novelty.
